# 奶龙：犯罪都市 / Nailong City

一款可离线运行的第三人称开放城市犯罪沙盒。程序化街区、海滨和公园，可步行、驾驶、枪战、抢劫、买卖装备，在五段连续委托中一路升级通缉与追逐。城市有完整昼夜循环：黄昏、路灯、亮起的窗户和夜空星辰。角色、车辆、建筑、音效与电台音乐全部由代码实时生成，未包含《GTA 5》的地图、音频、图像、代码或商标素材。

## 下载运行

Windows 10/11 x64 便携版：`npm run dist` 生成于 `release/`，双击 EXE 即可运行，无需安装 Node.js 或联网。若系统提示未知发布者，需要自行确认文件来源。游戏进度自动保存在本机；首次启动需要可用的图形加速环境。

## 内容

- **五段委托**：配送、限时竞速、便利店抢劫、清除目标与逃脱通缉，奖励累计 $4,000 以上。
- **枪械系统**：拳头、城市手枪、海风冲锋枪、港口霰弹枪；弹匣、备弹、换弹、散布、瞄准和命中检测。
- **通缉与警察**：五星通缉，徒步警员、警车追捕、路障、曳光弹与警笛；甩掉追兵或进医院清记录。
- **驾驶与损毁**：加速、手刹漂移、喇叭、车况、起火与爆炸；撞车会掉车况并提高通缉。
- **商店经济**：BROTHER 军火、圣心医院、奶龙潮衣、海风车行、24/7 便利店（可抢劫）。
- **昼夜与电台**：约 8 分钟一轮昼夜，夜间路灯与窗光；三个程序化电台频道。
- **城市 HUD**：圆形小地图、全城地图、任务指引、车速、武器弹药、护甲、体力、通缉星级与时停菜单。
- **触屏支持**：虚拟摇杆与开火、跳跃、上下车按钮。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动、驾驶 | WASD |
| 奔跑 | Shift |
| 跳跃、驾车手刹 | 空格 |
| 上下车、商店/修理站互动 | E |
| 射击 / 瞄准 | 鼠标左键 / 右键 |
| 换弹 | R |
| 切换武器 | 1-4 或 Q |
| 喇叭 | H（车内） |
| 车载电台 | T（车内） |
| 地图 | M |
| 暂停、设置与重新开始 | Esc |

靠近地图标记自动接取或完成委托。通缉等级随枪击、抢劫、撞人和碰撞上升；没有警察视线时冷却归零。

## 源码构建

需要 Node.js 20.19+、Windows x64。进入项目目录：

```powershell
npm install
npm run dev
npm test
npm run test:visual
npm run dist
```

可执行文件输出在 `release/`。`npm run dev` 启动本地开发页面；`npm run build` 生成离线网页；`npm start` 用 Electron 打开已构建页面；`npm run test:visual` 用 Edge 无头模式验证画面、驾驶、任务链、商店、射击、夜景与菜单并输出截图到 `screenshots/`。

使用 Three.js 进行渲染、cannon-es 进行碰撞、Vite 构建、Electron 包装。项目自己的源代码采用 MIT 许可；依赖及其许可归各自作者所有。游戏名称与任何第三方角色权利均不在本项目许可证授予范围内。
